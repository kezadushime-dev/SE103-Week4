What a pull request asks teammates to do:
A pull request asks teammates to review proposed changes before they are added to the main branch. It gives them a chance to check the work, discuss it, and approve the changes.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately from the main branch. Pull requests provide a way to review those changes before merging them into main.

One thing that confused me in this project and how I solved it:
I was initially confused about the difference between a branch and a pull request. I solved it by practicing the process of creating a branch, making a commit, pushing the branch, and creating a pull request. This helped me understand how the branch contains my work while the pull request is used to review and merge that work.
